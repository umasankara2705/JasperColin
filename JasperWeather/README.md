# JasperWeather (Expo + React Native)

Weather app with:
- GPS-based current weather
- City search
- 5-day forecast
- Multi-language support (EN/ES/HI)
- Light/Dark themes with animations

## Prerequisites

- Node.js 18+ (recommended: latest LTS)
- npm 9+
- Expo Go app on your phone, or Android/iOS emulator

## Setup After Clone

1. Clone and enter project

```bash
git clone <your-repo-url>
cd JasperWeather
```

2. Install dependencies

```bash
npm install
```

## Run the App

Start Metro:

```bash
npx expo start
```

Then open on:
- `a` for Android emulator
- `i` for iOS simulator (macOS)
- `w` for web
- or scan QR with Expo Go

## Helpful Scripts

```bash
npm run start
npm run android
npm run ios
npm run web
npm run lint
```
